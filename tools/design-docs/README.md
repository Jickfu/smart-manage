# 开发规范浏览入口

独立文档工具直接读取仓库 Markdown，不维护正文副本，不进入业务应用的依赖、菜单或构建。

从[开发规范首页](../../docs/design-entry.md)进入前端、后端、移动端及协作规范；[页面示例](../../docs/design/examples.md)和[图表示例](../../docs/design/chart-examples.md)展示通用用法，[设计建议](../../docs/proposals/frontend-design-spec/README.md)不作为开发门禁。

安装、预览、构建和验证命令只维护在[质量验证](../../docs/development/verification.md#文档浏览入口)，来源范围与维护方式见[规范站维护](../../docs/development/design-docs-site.md)。工具不包含业务 API、账号或外部发布流程。
