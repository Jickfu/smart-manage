# 前端开发规则

本文件适用于 `smart-manage-web`，同时继承根目录 `AGENTS.md`。

前端架构、技术基线和目录规则以[前端架构](../docs/architecture/frontend.md)为唯一事实来源；页面实现、样式、交互和模块开发规则统一见[模块开发指南](../docs/development/module-development-guide.md)，并在实现前从[模块样板目录](../docs/development/module-pattern-catalog.md)选择最接近的现有样板。本文件不重复具体规则。

## 验证

前端静态检查、测试、构建和页面注册生成验证统一遵守[质量验证](../docs/development/verification.md)，本文件不重复维护具体命令。
