- 一期包括定义管理、官方 iframe 设计器/流程图、顺序审批、条件分支、或签、同意/拒绝、待办/已办/我发起、记录和通知；会签、并行、转办、抄送后续再做。
- 指定用户、单据组织角色成员、单据组织负责人作为审批人规则；节点激活时确定候选人，空候选阻止推进；本人被配置时允许手动审批，不自动通过。
- 拒绝结束本轮；申请人修改后重新提交生成新实例，历史读取原轮次快照。
- 用户补充：仅申请人且无人完成实际审批时可撤回；撤回结束本轮，不能使用会重新生成任务的引擎 revoke 语义。提交和任务创建记录不计为已审批；首个实际审批提交后禁止撤回，审批与撤回需原子竞争。
- 申请人、当前候选人和实际历史处理人可查看对应轮次详情、附件与记录；流程管理权限不自动授予业务内容访问。
- 请假天数人工填写，保留两位小数；起止时间校验先后，不建设节假日、余额或考勤能力。
- 实施中用户追加确认：一期加入独立权限控制的当前任务候选人维护，记录原因、操作人和变更前后人员，不授予代审批权，不计为实际审批记录。
- 实施中用户追加确认：互斥网关的条件必须互不重叠；发布时拒绝可能同时满足的分支，不依赖保存顺序作为优先级；保留唯一默认分支。
