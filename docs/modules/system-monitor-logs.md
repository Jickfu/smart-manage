# 系统监控日志

## 模块边界

系统监控日志属于系统内核审计能力，当前包含登录日志和操作日志：

- 登录日志记录登录成功、登录失败和主动退出事件；
- 操作日志记录公开 Service 上 `@BizLog` 标注的业务命令；
- 两类日志只提供查询和详情能力，不提供修改、删除、清空或导出；
- SQL、脚本、任务执行日志属于各自监控模块，不并入本模块。

## 安全边界

- 日志不得记录 token、密码、验证码、私钥、密钥、存储凭据或一次性票据；
- 请求参数和响应正文只有在业务命令明确允许时记录，并在落库前脱敏、截断；
- 登录日志不保存 token 全文或任何 token 片段；
- 列表只返回排障必需字段，User-Agent、请求参数和响应正文仅在详情中返回；
- Trace ID 用于关联同一请求链路，不作为认证凭据。

## 查询契约

### 登录日志

- 支持用户名、昵称或 IP 关键字查询；
- 支持成功状态、事件类型、时间范围和完整 Trace ID 查询；
- 列表显示认证主体、事件、结果、IP、时间和 Trace ID；
- 详情额外返回失败原因和 User-Agent。

### 操作日志

- 支持请求 URI、方法名、业务名称或用户名关键字查询；
- 支持成功状态、时间范围和完整 Trace ID 查询；
- 列表显示业务名称、操作人、请求信息、耗时、结果、时间和 Trace ID；
- 详情额外返回类方法、错误信息、User-Agent、脱敏后的请求参数和响应正文。

开始时间晚于结束时间时查询必须失败，不得静默交换或忽略时间边界。

## 权限

| 能力 | 权限码 |
| --- | --- |
| 登录日志列表 | `sys:log:login:listPage` |
| 登录日志详情 | `sys:log:login:detail` |
| 操作日志列表 | `sys:log:operate:listPage` |
| 操作日志详情 | `sys:log:operate:detail` |

迁移会为已经拥有对应列表权限的角色补齐详情权限。

## 当前运行边界

- 日志通过独立线程池异步写入，业务事务不依赖日志落库成功；
- Trace ID 必须在异步执行时显式传播并在任务结束后清理；
- 当前不声明长期归档、自动清理、实时推送、全文检索和多节点集中采集能力；
- 上述能力如需启用，必须先明确保留周期、容量、安全和部署边界。
