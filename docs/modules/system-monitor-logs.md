# 系统监控日志

## 模块边界

系统监控日志属于系统内核审计能力，当前包含登录日志和操作日志：

- 登录日志记录登录成功、登录失败和主动退出事件；
- 操作日志记录公开 Service 上 `@BizLog` 标注的业务命令；
- 两类日志只提供查询和详情能力，不提供修改、删除、清空或导出；
- SQL、脚本、任务执行日志属于各自监控模块，不并入本模块。

登录日志区分以下事件，不得把所有 Sa-Token 下线回调统一记录为主动退出：

| 事件 | 语义 |
| --- | --- |
| `LOGIN_SUCCESS` | 已创建正式登录会话 |
| `LOGIN_FAILURE` | 验证码、凭据或账户状态校验失败 |
| `PASSWORD_CHANGE_REQUIRED` | 凭据正确但必须先修改密码，尚未创建正式会话 |
| `LOGOUT` | 用户主动退出 |
| `SESSION_KICKED` | 管理员或安全事件强制下线 |
| `SESSION_REPLACED` | 同账号会话被新会话顶替 |
| `ACCOUNT_DISABLED` | 账户禁用导致会话终止 |
| `PASSWORD_RESET_TERMINATED` | 管理员重置密码导致既有会话终止 |

用户启用、分配角色和修改角色权限只刷新共享授权缓存，不终止现有会话；用户禁用、管理员重置密码及其他安全事件刷新授权缓存后终止全部会话。缓存刷新和会话终止必须使用不同方法表达，禁止重新合并为一个无差别 logout 操作。

认证时生成不可变日志快照，包含 userId、username、nickname、事件、结果、失败原因、IP、User-Agent 和 Trace ID；异步写入不得重新依赖可能过期的用户缓存。日志禁止记录密码、验证码、token 和一次性改密票据。

## 安全边界

- 日志不得记录 token、密码、验证码、私钥、密钥、存储凭据或一次性票据；
- 请求参数和响应正文只有在业务命令明确允许时记录，并在落库前脱敏、截断；
- 登录日志不保存 token 全文或任何 token 片段；
- 列表只返回排障必需字段，User-Agent、请求参数和响应正文仅在详情中返回；
- Trace ID 用于关联同一请求链路，不作为认证凭据。

## 查询契约

### 登录日志

- 支持用户名、昵称或 IP 关键字查询；
- 支持成功状态、事件类型、时间范围和完整 Trace ID 查询；
- 列表显示认证主体、事件、结果、IP、时间和 Trace ID；
- 详情额外返回失败原因和 User-Agent。

### 操作日志

- 支持请求 URI、方法名、业务名称或用户名关键字查询；
- 支持成功状态、时间范围和完整 Trace ID 查询；
- 列表显示业务名称、操作人、请求信息、耗时、结果、时间和 Trace ID；
- 详情额外返回类方法、错误信息、User-Agent、脱敏后的请求参数和响应正文。

开始时间晚于结束时间时查询必须失败，不得静默交换或忽略时间边界。

## 权限

| 能力 | 权限码 |
| --- | --- |
| 登录日志列表 | `sys:log:login:listPage` |
| 登录日志详情 | `sys:log:login:detail` |
| 操作日志列表 | `sys:log:operate:listPage` |
| 操作日志详情 | `sys:log:operate:detail` |

迁移会为已经拥有对应列表权限的角色补齐详情权限。

## 当前运行边界

- 日志通过独立线程池异步写入，业务事务不依赖日志落库成功；
- Trace ID 必须在异步执行时显式传播并在任务结束后清理；
- 数据库审计日志由所有实例写入共享 PostgreSQL；在线表、历史表、月分区、默认保留周期和内置任务遵循[日志数据生命周期](../architecture/log-lifecycle.md)；
- 历史日志不进入普通页面，只允许管理员通过 SQL 控制台按明确时间范围排障；
- 当前不声明实时推送和数据库全文检索能力，多实例运行日志必须携带实例 ID 并汇聚到统一日志采集设施。
