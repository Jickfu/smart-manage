# 项目路线图

本文只记录已经批准、尚未完成的项目级事项。详细设计进入架构文档或 ADR，执行细节不在本文展开；已完成事项从正文删除，通过代码、测试和 Git 历史追溯。

维护规则：

1. 每项只包含目标、剩余工作和完成条件。
2. 不记录每日进度、测试数量、构建体积或已经失效的实施步骤。
3. 未批准方案只放在 `proposals/`，不进入本路线图。
4. 正文保持精简；接近 150 行时必须清理，将执行细节迁入对应架构、开发或领域文档。

## 生产部署与恢复验收

- 状态：待部署环境落地
- 目标：确认系统能够在生产等价环境安全部署、以多实例方式稳定运行，并在故障或发布失败后恢复。
- 剩余工作：完成 Cookie、CSRF、Origin、CSP、高风险入口关闭、管理员初始凭据和浏览器加载验证；完成无粘性登录、Quartz 唯一获取、跨节点附件读写、资源互斥与单实例退出恢复的双实例验收；配置集群外部的可用性探测和通知；演练备份恢复及发布失败后的恢复路径。
- 完成条件：生产安全策略不影响正常使用且能够阻止非允许访问；双实例和单实例退出场景通过验收；集群整体不可达时仍能从外部发出通知；备份能够恢复，发布失败具有经过演练的恢复方案。
