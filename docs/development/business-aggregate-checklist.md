# 新增业务聚合检查清单

本清单用于后续 ERP、MES 业务聚合开发，将[后端架构](../architecture/backend.md)、[前端架构](../architecture/frontend.md)、[模块开发指南](./module-development-guide.md)、[安全架构](../architecture/security.md)和[质量验证](./verification.md)中的生效规则转换为验收项，不作为独立规则来源，也不复制采购申请的具体字段。是否启动新聚合仍以[项目路线图](../roadmap.md)中的阶段门槛为准。

## 1. 聚合和目录

- 公开 `*Service` 按清晰、内聚的业务职责划分；同一模块可以拥有多个不同语义的公开 Service，不得为追求单一入口将无关职责堆入一个大 Service。
- 写操作集中在同目录、包级可见的 `*TxService`。
- 明细使用 `*Entry`，只提供 Entity、Mapper、Form、VO，不建立独立写入口。
- 系统内核不得依赖可选业务领域。

## 2. 数据模型

- Entity、Form、后端 VO 的雪花 ID 使用 `Long`。
- JSON 边界将 Long 统一序列化为字符串，前端 ID 使用 `string`。
- 可修改聚合包含 `version`，所有修改命令必须携带版本。
- 业务单据继承 `BaseBillEntity` 并使用统一 `org_id` 表达所属组织；申请人、采购员、经办人等角色字段只放在确实具有该语义的具体聚合中。
- 主从表即使没有明细，接口也返回 `entries: []`。
- 数据库结构和初始化数据只通过新增 Flyway 迁移维护。

## 3. 查询和转换

- 纯字段 `Entity → VO` 使用模块内 `*Converter`。
- Converter 不依赖 Mapper、Service、缓存、安全上下文或外部资源。
- 联表查询可以由 MyBatis 直接投影 VO。
- 查询、权限、树结构、缓存和运行态信息使用 `assemble...` 显式组装。

## 4. 命令和事务

- `save` 明确区分新增和暂存修改。
- `submit` 接收页面当前完整聚合，在同一事务内保存并推进状态，不要求用户先执行 `save`。
- 已有单据提交以后端数据库状态和 version 为准，只允许合法状态流转；新增单据允许直接提交。
- 修改、提交和删除同时校验 ID、状态和 version。
- 主单和明细在同一事务内写入，失败时整体回滚。
- 删除主单前显式删除明细，不依赖数据库级联删除。
- `@BizLog` 只放在公开 Service 命令方法。

## 5. 权限和安全

- Controller 声明业务权限码。
- 高风险能力在公开 Service 额外校验 `administrator`。
- 日志不得记录 token、密码、验证码、密钥和存储凭据。
- 业务异常由统一异常处理返回，不用 `null` 表示失败。
- 聚合使用附件等通用能力时，在自身模块显式注册稳定业务资源类型和授权策略；不使用附件时不增加空注册。
- 新聚合必须声明数据归属字段和未来数据范围规则；全局数据权限启用前不得宣称已完成组织级或行级隔离。
- 附件授权至少区分读取、绑定、解除和删除，并覆盖申请人、审批人、负责人、数据范围及单据状态等实际规则。
- 未注册资源类型必须默认拒绝；补充跨用户、跨单据和非法资源类型的越权测试。

## 6. 前端生命周期

- 页面注册使用稳定业务键和白名单注册表。
- 列表、详情和命令分别使用 Query Key Factory 与领域 Mutation。
- 新增页使用临时页签，保存后替换为真实单据页签。
- 保存后重新查询详情，不继续信任提交前的表单状态。
- 已提交等只读状态进入 `VIEW`，不能普通保存。
- 新增和编辑页面都注册脏数据关闭确认。
- 页面壳层只负责布局、加载、错误、权限和按钮区。
- 基础组件负责字段、过滤、表格和引用选择器。
- 业务页面负责状态流转、Mutation、明细聚合和业务命令。

## 7. 最低风险验证

- 新增保存主从数据。
- 暂存修改成功。
- 非暂存状态禁止保存。
- 过期 version 修改、提交和删除失败。
- 原子更新条件不匹配时返回并发冲突。
- 主单或明细写入失败时事务回滚。
- 临时页签替换、详情回显和脏数据关闭。
- 权限、操作日志和缓存失效符合统一约定。
- 使用附件时，临时附件所有权、正式附件继承单据权限及未知类型拒绝均有测试。

不要求为 Getter、Setter、普通 CRUD、简单 Converter 或框架生成代码编写测试，也不设置覆盖率目标。
