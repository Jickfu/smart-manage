# 移动端规范

适用手机浏览器与小程序，面向未来客户端的通用设计和接入。当前没有移动端运行工程；小程序平台与技术栈未选定，不承诺所有宿主平台能力一致。

## 适用边界

移动端沿用[组件适配边界](../design/adaptation-boundaries.md)，依据真实任务与平台公开能力实现。桌面 Ant Design 组件、页签、页面注册、密度及 ECharts 渲染方式不自动适用于移动端；不为追求桌面代码复用建立无需求的跨端适配层。

权限与会话遵守[安全架构](../architecture/security.md)，对象范围遵守[数据权限](../architecture/data-permission.md)，响应与缓存中的敏感字段遵守[数据脱敏](../architecture/data-masking.md)。这些服务端约束不因客户端变化而降低；浏览器 Cookie／CSRF、平台登录凭证和服务间 OpenAPI 是不同接入边界，不能直接把桌面登录或服务间密钥搬进小程序。具体登录接入在平台确定后设计，本规范不预设新的认证协议。

## 查询列表

列表围绕真实查询任务组织，不把桌面左树、工具栏、操作列或工作台页签缩小后直接搬入手机。筛选入口、已应用条件和清除／重置的结果应可理解，业务必需条件不能通过清空入口移除；排序及筛选字段以实际服务端支持为准。

- 筛选面板中的待提交条件与已应用条件分开管理。取消或可拦截返回时保留已应用条件；确认后再更新列表与条件摘要。清除只修改待提交条件还是立即查询，必须在入口语义中明确，不能关闭面板后才发现列表已被修改。
- 分页或加载更多按数据规模和接口选择，不默认建设两套能力。变更筛选、排序或组织范围后，从新条件的起点取数，不能把旧条件记录继续拼接；较晚返回的旧请求不得覆盖当前条件结果。
- 首次加载、正在刷新、加载下一段、无记录、已到底及请求失败应能区分。加载更多失败保留已成功加载记录和当前位置，重试针对失败部分，不重复追加；刷新失败不能把旧数据伪装成新结果。是否保留旧数据及其标记、有效期按数据敏感性和任务确定。
- 返回列表时明确恢复的条件、排序、已加载范围与滚动位置；详情发生变化、权限变化或数据已过期时重新核实，不保证任意缓存都能原样恢复。恢复滚动需与数据恢复顺序一致，不用重新加载第一页造成位置与内容错配。
- 使用业务稳定 ID 识别记录，不使用列表下标表达对象身份。数据持续变化时按接口的真实分页契约处理重复、遗漏及刷新提示，不声称前端去重即可获得一致快照，也不虚构游标或快照接口。

列表缓存与未完成请求必须绑定账号、组织范围及已应用查询条件。账号、组织或会话发生变化后，旧请求即使成功返回也不得重新填充当前列表或详情；取消请求是优化手段，不能代替接收结果时的身份与查询上下文检查。

## 详情与完整值

详情入口携带稳定对象身份，服务端重新执行对象授权；列表可见、缓存命中或分享链接存在都不能代替详情授权。支持直接进入或分享时，单独验证登录恢复、对象不存在和无权限路径，不暴露不可访问对象的历史内容。

从列表进入详情时保留可恢复的来源；直接入口没有列表历史时，返回应提供明确且可访问的上级入口，不假定总能后退到列表。登录恢复只恢复导航意图，重新授权取数，不自动恢复提交风险命令。

字段按任务优先级展示，区分加载中、未填写、未知和明确为零。金额、数量、单位及负号遵守[关键值完整显示](../design/foundations.md#关键金额与数量)，可调整分组、换行或所属区域滚动，不能以悬停、长按或缩写作为唯一完整访问方式。普通长文本保留展开或完整阅读入口，不能仅靠省略号结束。

从缓存恢复时按任务标识数据新旧并核实权限；会话失效、对象访问被拒绝或账号／组织切换时，不继续显示不再有权访问的旧详情。清理与隔离规则沿用安全和隐私要求，不能把接口脱敏当成本地长期存储原始数据的授权。

附件、复制、拨号、下载等入口只在实际业务和平台能力支持时提供；明确权限拒绝、取消与失败结果，不将平台接口调用成功等同于用户已取得文件。详情图表沿用[图表表达规范](../design/charts.md)，其 React 封装与 SVG 渲染不因此成为移动端技术要求。

## 风险确认

**M-06 必须。** 删除、清空等风险确认通过明确按钮取消或确认，点击遮罩不关闭。操作处理中禁止关闭和重复提交；提示明确对象、影响及后果。

应用可拦截的返回入口执行同一策略；平台系统强制退出无法保证阻止时，不声称已取消命令，重进后核实服务端结果。发出命令后的网络失败不自动表示未执行。普通信息弹层不因此一律禁止关闭，具体关闭策略按任务明确。

### 命令状态与恢复

确认内容绑定本次操作的对象与参数快照；选中项、数量或影响范围变化后重新核实，不能让说明指向一组对象、实际提交另一组。服务端在执行时重新检查权限、对象状态和并发条件，弹框展示不作为授权证明。

| 状态 | 共通要求 |
| --- | --- |
| 待确认 | 展示对象、范围及后果；取消不发命令，确认入口可明确识别 |
| 执行中 | 异步命令或回执尚未完成时维持处理中状态，执行 M-06 的防关闭和防重复策略；不以请求已经发出作为完成 |
| 明确成功 | 依据服务端结果更新对象与列表；后续刷新失败单独反馈，不重复执行已成功命令 |
| 明确失败 | 显示可信且安全的原因，保留必要输入；仅在服务端契约允许时提供重试，重新核实条件 |
| 结果未知 | 超时、断网或被宿主中断后不显示“已取消”或直接重发；按已有结果查询、回执或详情重新确认，没有恢复能力时说明尚待核实 |

版本冲突或对象状态变化后，重新读取并展示当前信息，由用户重新确认；不得用新版本号自动重发旧确认。删除成功后退出失效详情并更新来源列表；详情刷新返回不存在本身不能证明某次未知命令已成功，应依据实际服务端契约判断。

幂等、请求身份与结果未知的服务端要求统一见[命令重试与结果不确定](../architecture/backend.md#命令重试与结果不确定)。客户端防连点不能替代服务端幂等，也不意味着所有普通命令都要新增回执表。离线写入、后台自动重试和挂起后恢复提交均不预设支持；真实业务需要时先明确其副作用与授权边界。

## 平台适配

| 能力 | 手机浏览器 | 小程序 |
| --- | --- | --- |
| 导航与返回 | 历史栈、刷新、深链及离开页面 | 宿主页面栈、返回、入口与恢复 |
| 视口与键盘 | 地址栏变化、横竖屏、软键盘遮挡 | 宿主标题区、安全区、键盘与滚动能力 |
| 登录与会话 | 会话过期、跨源及登录后恢复 | 平台凭证与项目账号映射、授权及会话恢复 |
| 文件与附件 | 选择、上传、下载、预览和取消 | 宿主授权、临时文件、预览与分享限制 |
| 网络与前后台 | 弱网、断网、重连及后台冻结 | 挂起、恢复、中断与宿主请求限制 |
| 本地数据与发布 | 缓存、敏感数据清理、静态版本兼容 | 存储隔离、配额、平台审核与版本分布 |
| 图表与长列表 | 尺寸变化、触摸与渲染性能 | 渲染环境、组件支持与包体限制 |

具体客户端在实际需求下明确支持的平台、设备和版本范围，以及认证、安全与发布方案。不预设导航高度、单位换算、授权接口、文件 API 或离线写入能力。

## 页面与验证

### 查询页规划

在没有客户端工程时，查询页规划应明确以下输入，直接纳入对应功能设计，不另建移动端流水账：

- 用户任务、入口、列表与详情的信息优先级，筛选、分页或加载更多、返回及滚动恢复策略。
- 已有接口能否满足条件、排序、分页、完整数值与详情展示；缺少的契约明确为待实现，不虚构接口能力或预建通用适配层。
- 认证、功能权限、对象范围及隐私字段以[服务端规则](../backend/README.md)为准，隐藏入口不能替代服务端授权；查询页不因只读而默认公开。
- 加载、空结果、无权限、会话失效、断网和失败重试的可见结果；前后台恢复时如何重新确认数据有效性。
- 手机浏览器与小程序的共通要求、待平台确定后才能验证的能力，以及后续真机验收场景。平台未知项保留为明确待决边界，不自行指定宿主或技术栈。

上述输入可评审且未决项及其影响清楚时，可判定规划完成；这不等于客户端实现或平台验收完成。实际开发后按下列场景及质量验证执行适用检查。

### 页面场景

| 场景 | 设计与验证输入 |
| --- | --- |
| 列表与筛选 | 条件、分页或加载更多、刷新、滚动恢复、空结果与失败重试 |
| 详情与数值 | 信息优先级、单位、长内容与[关键值完整显示](../design/foundations.md#关键金额与数量) |
| 编辑与输入 | 字段、校验、焦点、键盘遮挡、失败后输入与脏数据离开 |
| 选择与附件 | 已选回显、取消、权限拒绝、上传与预览失败 |
| 风险操作 | 明确对象、确认/取消、连点、返回、中断与结果恢复 |
| 状态与可访问性 | 加载、无权限、离线、超时、文字缩放与辅助能力 |

验证按[质量验证](../development/verification.md)执行；浏览器窄屏预览不替代手机或小程序真机。权限、对象访问和隐私继续遵守[安全架构](../architecture/security.md)与相关服务端契约。

### 场景验收基线

以下定义未来实现时需覆盖的行为，不表示当前已有移动运行能力。自动化、设备及构建命令按[移动端验证边界](../development/verification.md#移动端验证边界)选择，未具备的运行环境如实列为未验证。

| 场景 | 至少核对 |
| --- | --- |
| 查询列表 | 筛选草稿取消与确认、筛选／排序切换与请求乱序、空结果、分页末尾、加载更多失败重试、刷新失败及返回恢复；账号／组织切换后旧请求返回不得回填 |
| 详情 | 列表进入与直接进入的返回路径、登录恢复、无权限／不存在、缓存过期、账号／组织切换、大额／负值／零／缺失与长文本 |
| 风险操作 | 取消不提交、连点、遮罩及可拦截返回、版本冲突重新确认、成功后刷新失败、删除后退出失效详情、明确失败、断网结果未知、挂起或退出后核实结果；登录恢复不自动提交 |
| 平台交互 | 真实视口、键盘、安全区、触摸及辅助能力；仅在实际使用时验证附件、分享、图表和宿主授权 |

字号、密度、触摸目标及具体模式仍见[待议设计建议](../proposals/frontend-design-spec/README.md#移动端设计)，不能把未确认数值作为跨平台兼容保证。
