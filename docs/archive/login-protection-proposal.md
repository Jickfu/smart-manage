# 登录保护方案（历史提案）

## 状态

`已于 2026-08-21 完成复审并由现行架构替代`

早期提案提出账号/IP失败窗口、短时锁定、验证码频率限制、成功清理和统一反馈。实施前复审调整了以下结论：

- 字符验证码改为点击登录后弹出的滑块拼图；
- 增加账号与 IP 组合维度，账号全局限制只允许短时保护；
- 验证码使用挑战、原子消费和短时一次性票据协议；
- 运行阈值统一由系统内置参数维护，不再拆分 YAML 和动态参数；
- Redis 故障固定失败关闭，不提供降级登录；
- 首版不启用文字点选和动态风险评分。

当前有效规则见[登录保护架构](../architecture/login-protection.md)和[安全架构](../architecture/security.md)。
