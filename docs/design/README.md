## 总原则

**F-03 必须。** 在 Ant Design、ECharts 公开支持且维护成本合理的配置和扩展范围内形成项目体验；业务正确性、组件语义、架构清晰和可升级性优先于外观完全一致。无法合理适配时采用最接近的原生表现，记录并接受差异，不为外观复刻大改组件库、图表引擎或叠加特殊处理。

参数表达设计基线，不承诺依赖升级后逐像素不变。关键数值、权限和风险要求仍须满足；通过布局与任务设计解决库能力差异，不能以保持原生为由降低业务要求。
