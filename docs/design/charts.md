# 可视化范围与能力

[返回规范入口](./README.md)。本章维护已确认的规范建设范围和当前能力边界；配色、趋势表达、完整值访问与异常表达见下文；其它视觉参数和候选数据契约尚未整体采纳。

## 已确认范围

适用范围包括浅色管理端的折线、饼/环形、仪表盘和柱/条形图；其它图型保留选型指引，深色大屏待实际需求另行设计。这是规范与后续实施的范围，不是全部能力已实现的声明。

图表适配遵循[组件边界](./adaptation-boundaries.md)：优先公开 theme、色板与标准 option；接受自动刻度、标签避让、节点和提示定位的合理差异，不为复刻外观修改渲染内部或用复杂自绘替代内置图型。

| 入口 | 当前能力 | 不代表 |

## 业务接入示例

`SmChart` 当前只接收必填的 `option` 和 `ariaLabel`，不透传 ECharts 实例、事件、theme、loading、height 或任意 div 属性。主题入口目前仅合并基础文字色，不能据此宣称分类色板、缺失值处理或异常状态已自动生效。所需公开能力尚未暴露时先核实真实需求，不向示例虚构 props。

```tsx contract=sm-chart
import { useMemo } from 'react';
import SmChart from '@/domain/common/chart/SmChart';

export function TrendExample({ points }: { points: [number, number | null][] }) {
  const option = useMemo(() => ({
    color: ['#0E5FD8'],
    xAxis: { type: 'time' },
    yAxis: { type: 'value' },
    series: [{
      name: '示例指标',
      type: 'line',
      smooth: false,
      connectNulls: false,
      data: points,
    }],
  }), [points]);
  return <SmChart option={option} ariaLabel="示例指标随时间变化的趋势" />;
}
```

`points` 的时间戳使用毫秒；`null` 表达真实缺失。该片段只演示图型接入，单位、时间口径、状态及完整数据入口由实际页面提供，不得原样充当重要分析页面。业务保持输入引用稳定，避免无意义地重建 `option`：当前封装在 `option` 或文字色变化时销毁并新建实例，不能依赖图例选择、缩放或动画状态自动保留。

加载、无权限、失败、无记录、构成负值及仪表盘越界等判断在领域页面完成；`SmChart` 不解释这些业务状态。容器默认最小高度为 240px，这是现行 CSS 行为，不是通用设计高度；额外布局使用所属样式文件，不向封装传入不存在的高度参数。

## 分类色与语义色

**C-11 必须。** 一般无序分类使用以下首批分类色板；成功、失败、跳过等明确业务状态使用项目语义色，不把状态色当作全部图表的通用分类色。

| 角色 | 色值 |
| --- | --- |
| 分类 1–6 | `#0E5FD8`、`#0F766E`、`#8B5CF6`、`#B45309`、`#BE185D`、`#475569` |
| 任务成功 | `#1BA854` |
| 任务失败 | `#FB2323` |
| 任务跳过 | `#FF991C` |

颜色不单独承担含义，保留系列名称、图例及必要的非颜色区分；收益和损失不自动套用成功/失败语义。同名系列保持稳定映射，不因隐藏其它系列而漂移颜色；不要按不同图中的临时数组下标猜测业务系列身份。

采用前以实际业务数据、系列数量、图幅与主题检查可读性及色觉差异。色板采纳不代表所有颜色组合已完成对比度验证，也不要求为更多类别简单循环配色或删除真实类别；超过可读范围时评审布局、聚合和完整数据入口。

实施仍使用 ECharts 公开 color/itemStyle 等配置及现有公共入口，按具体任务接入。规范与独立试样不替代业务接入，不宣称存量图表已全部适配。

## 趋势表达

**C-12 必须。** 普通趋势默认不平滑，缺失处断线；保留缺失与零值的区别，不为连接曲线将缺失补零或跨越缺失点连线。系列除颜色外，通过适合当前密度的线型、标记或明确名称辅助区分。

密集数据可按场景减少常驻标记；2px 线宽、6px 标记只是试样，不是所有图表的固定要求。确有业务依据需要其它趋势表达时说明指标含义及取舍，不能仅为视觉圆滑改变走势含义。

## 完整数值访问

**C-13 必须。** 重要分析提供完整数据表或明确的数据详情入口，不只依赖悬停提示。已有列表或详情能表达对应指标时优先复用，不要求每张图重复建设一张表。

完整入口保留维度、原值、单位与口径，关键金额和数量继续遵守[完整值规则](./foundations.md#关键金额与数量)。原生图例只影响图形可见系列时，说明完整数据入口是否仍为全量口径，不让用户将图形筛选误认为数据口径已经变化。图像的 aria-label 不代替完整数据访问。

聚合数据必须说明查询范围、时间桶粒度及指标采用的平均、最大或求和口径。完整数据入口的“原值”指本次查询返回值，不能暗示为全部底层采样或事件明细；单位换算不得改变统计含义。百分位的平均值或最大值不等于整个范围重新计算的百分位，名称或说明必须明确区分。具体指标定义归所属模块文档，例如[运行监控历史趋势](../platform/monitor/runtime-monitoring.md#历史趋势口径)。

## 构成图的零值与负值

**C-14 必须。** 饼图和环形图全为零时，明确表达成功查询后的零结果，不绘制等分扇区，不将其混同于没有记录。数据中存在负值时停止绘制构成图，说明原因并保留完整原值，不取绝对值、不丢弃负项后继续计算占比。

需要继续比较正负值时，按实际业务选择条形等适合的表达；不得为了保留饼图外观而改变原始数据含义。具体图型变更仍按任务范围实施。

## 仪表盘越界

**C-15 必须。** 仪表盘实际值低于下界或高于上界时，显示实际值和范围说明，暂停绘制指针，不将值截成边界，也不静默放大量程。例如量程 0–100% 而实际为 135% 时，应让用户直接读到 135% 和越界原因，而不是看到 100%。

是否调整量程、阈值或改用其它图型由业务决定；试样中的 0–100% 量程和 80% 目标不作为通用业务阈值。

## 实施与验收边界

以上要求适用于后续新增及相关修改，存量图表按任务单独适配。规范与独立试样不代表现有平滑折线、数据入口或异常状态已全站符合，具体接入与验收按业务任务实施。

实施使用 ECharts 公开 option 和既有页面/数据能力，遵守[组件适配边界](./adaptation-boundaries.md)。验证覆盖普通趋势、真实缺失点、完整值入口、构成全零/负值及仪表盘上下界外值；具体命令仍由[质量验证](../development/verification.md)维护。试样已验证的状态不代替真实业务口径、权限、请求错误和数据往返验收。
