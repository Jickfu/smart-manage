# 设计基础

[返回规范入口](./README.md)。本章维护已采纳的桌面基础视觉和关键值要求；参数事实以[theme.ts](../../smart-manage-web/src/styles/theme.ts)、[themePalette.ts](../../smart-manage-web/src/styles/themePalette.ts)及[global.css](../../smart-manage-web/src/styles/global.css)核对。所有数值默认为 CSS px，不等于物理像素或小程序单位。

## 主题与色彩

**F-10 必须。** 颜色通过集中主题按角色使用。品牌仅从内置方案选择，不因换肤改变功能色与中性色；业务页面不以局部颜色覆盖公共状态。图表色板与界面品牌不是同一体系，尚未采纳的图表色值不写入主题。

下表是当前参数快照，不是要求业务页面硬编码；变更集中入口后同步更新本表。

| 角色 | 当前值 |
| --- | --- |
| 默认品牌 | `#276FF5`；共 12 个内置方案 |
| 安全链接 | 默认 `#0E5FD8`，悬停 `#0041B0`，按下 `#002D87` |
| 成功、警告、错误 | `#1BA854`、`#FF991C`、`#FB2323` |
| 主文字、次文字 | `#212121`、`#666666` |
| 三级、四级文字 | `#999999`、`#B2B2B2` |
| 控件边界、分隔 | `#D9D9D9`、`#E5E5E5` |
| 工作区、内容容器 | `#E2E7EF`、`#FFFFFF` |
| 弱填充、导航深底 | `#F5F5F5`、`#343848` |
| 全局圆角 | 2；专门组件和产品骨架按其既有语义 |

参数表不证明所有颜色组合均通过对比度验证，也不表示产品整体支持深色主题。适配程度遵循[组件边界](./adaptation-boundaries.md)。

## 字体与密度

**F-12 必须。** 全局字号基线由主题统一维护：正文、标签、按钮及普通操作控件使用 12；Input、InputNumber、Select、TreeSelect、Cascader、DatePicker、Mentions、ColorPicker 等可录入或选择控件的默认字段值为 14。RefSelector、IconSelector 等自定义输入同样保持 14。

EditableDetailTable 是统一紧凑边界，单元格内标准和自定义输入统一为 12，业务不各自覆盖；其它 small 输入只有在经过验证的紧凑边界内才用 12。不得为获得默认密度在 CSS 重复声明 `font-size: 12px` 或 `font-size: var(--ant-font-size-sm)`，也不得局部 ConfigProvider 复制全局字号主题。

显式字号仅用于不能由全局主题表达的标题或产品骨架、图标尺寸、特殊展示内容。页面标题、应用导航、内容页签、卡片/分区标题保持同类样板层级；图标字号不作为重复正文覆盖清理；品牌文字、数据主值、代码编辑器等由真实需要驱动。无法归类的字号先核对同类页面和最终计算样式，不直接新增。

新增或修改字号优先使用全局/组件 token；局部语义确有不同且扩大主题影响不合理时才使用 CSS。清理覆盖后检查表单、表格、树、分页、弹层和自定义控件的最终字号，确认标题、图标、行高、截断和垂直居中无回归。

| 参数快照 | 当前值 |
| --- | --- |
| 正文行高 | 1.5 |
| 普通/小/大控件高 | 28 / 24 / 32 |
| 普通/小/大按钮字号 | 12 / 12 / 14 |
| Card 标题、Modal 标题 | 14 / 16 |

这些是桌面值，不自动成为手机字号或触摸密度。

## 空间与边界

**F-13 必须。** 页面内容与工作台边界、独立同级卡片或块状容器保持 10 间隔；使用通用壳层不重复叠加页面级 padding。页面头部没有操作、筛选或状态内容时不渲染空占位。

提示与关联卡片组成一个视觉单元，内部间距为 0，组合与其它独立块仍保持 10；具体范围与插槽接入见[页面与分区提示](../development/frontend-page-guide.md#页面与分区提示)。普通弹窗按钮间距由[公共页脚](../development/frontend-page-guide.md#弹框页脚按钮)维护，不能因为页面间隔为 10 而一并改动。

表格表头上边框由全局样式提供，紧邻表格的标题/统计栏不再画下边框，避免双线；同一区域还有空态或提示时，仅在紧邻表格状态移除重复边框。填充高度表格的空态处理见[表格空状态](../development/frontend-page-guide.md#表格空状态)。

通用空间 token 当前为 4/8/12/16/20/24，分别服务组件内部；不能把页面、字段、卡片和命令所有间隔统一替换成某个数字。首页布局仍按[应用首页](../development/frontend-page-guide.md#应用首页)。

## 关键金额与数量

**F-18 必须。** 关键金额和数量直接完整显示，优先调整列宽、列组合或布局，必要时允许所属表格横向滚动。悬停提示不能作为唯一完整访问方式；不得省略、静默裁切或自动缩到不可读。

关键值由业务定义，例如付款金额、审批总额和库存可用数量；金额明确币种、精度、分隔符与负号，数量明确单位。办理/核对区域的 `123,456,789.00` 不能仅显示成 `123,456…` 或 `1.23亿`；概览可另提供明确单位的摘要，但不能代替关键完整值。

普通文本继续按[列省略声明](../development/frontend-page-guide.md#列表和命令)处理，特殊列通过现有有注释的例外声明表达，不全局关闭省略或放宽门禁。规则适用于后续新增与相关修改；存量关键列识别、集中适配和机械检查增强需独立实施，具体适配按实际变更范围验证。

验收包括大额、负值、零、小数、币种/单位及窄区域；完整显示值、原始业务含义和复制结果应一致。
