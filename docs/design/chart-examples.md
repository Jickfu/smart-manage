# 图表示例

浅色管理端折线、柱/条形、饼/环形和仪表盘的通用用法。数据为本地固定模拟，不连接业务接口。设计要求见[图表规范](./charts.md)，本页不维护第二份规则。

## 使用方式

选择正常、单项、全零、无记录、加载、失败、旧数据、无权限或边界数据，比较各图型表达。柱/条形与饼/环形可切换，同一组原始数据保留在图下可展开的表格中。模拟重试只切换示例状态，不代表真实接口能力。

| 示例 | 展示目的 |
| --- | --- |
| 金额趋势 | 不等时间间隔、缺失断点、线型辅助区分和完整金额 |
| 部门比较 | 柱/条方向、长名称、状态语义色及包含负值的金额净变动 |
| 构成 | 同总体金额与比例；全零不画等分扇区，负值保留原值但不绘制构成 |
| 达成率 | 实际值、量程和目标；越界时展示原值并暂停指针 |

## 参数与能力边界

示例使用 ECharts 的公开系列、轴、图例、提示和 SVG 渲染能力；通过尺寸观察调整容器，卸载时释放实例。不修改内部渲染或生成的图形节点，不构成新的业务图表封装。

本页由独立文档工程的 Vue 示例组件渲染，不使用业务端 React `SmChart`，其事件、更新和状态控制不能直接视为业务组件契约。业务接入以[当前封装与接入片段](./charts.md#业务接入示例)为准，复用图表语义时按实际接口重新接入状态和完整数据入口。

字体、线宽、标记、卡片高度、数据精度和阈值只为本示例服务。0–100% 量程、80% 目标、UTC 日期与两位金额小数不成为全部业务的固定口径。按任务核对数据含义、数量级与单位，保留完整访问路径。

图例只改变图形可见系列，原值表仍为全量口径；构成占比四舍五入后可能不恰好合计 100%，不得改动原值凑整。极差过大时考虑分图或其它表达，不能通过裁掉负值或缺失值美化走势。

状态演示不替代真实鉴权、请求失败、缓存更新或服务端聚合验证。原值表提供无需悬停的阅读入口，不等于全部原生图例操作已经通过键盘和读屏验收。窄区域预览不等于手机真机或小程序兼容保证。
