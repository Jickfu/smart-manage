## 窄窗口滚动

桌面管理端的主布局最小宽度为 `960px`，覆盖顶部导航、首页和工作台。浏览器比主布局窄时，统一使用主布局底部的横向滚动条访问右侧内容。页面按实际布局宽度排版，首页四轨按可用空间等分并保留跨列比例。页面纵向滚动与宽表的内部横向滚动仍由各自容器承担。

标准业务弹框使用声明的桌面宽度。放不进浏览器时，弹层从左侧显示并提供独立的横向滚动条，用户可以拖动到右侧字段和操作区。表单列数仍按弹框正文宽度确定。验收覆盖约 `500px` 宽的首页、工作台和标准业务弹框，以及窗口变宽后滚动条消失的行为。

## 命令视觉与顺序

**D-05 必须。** ListPage、EditPage、EditPageShell 及 CUSTOM 自定义顶部操作区的普通命令统一 primary；删除、清空、强制执行等造成数据丢失、不可逆变更或明显安全风险的命令使用 danger。这不表示弹窗决策中的所有按钮均为主色。

顶部从左至右为影响命令上下文的选择/配置控件，新增、保存、提交、执行等主要命令，查看、复制、刷新等辅助命令，最后是删除、清空等危险命令。明确业务流程可调整，但相关命令相邻且说明原因；权限过滤保留声明顺序，danger 不代表自动排序。具体接入见[有序声明](../development/frontend-page-guide.md#页面操作的有序声明)。

**F-15 必须。** 未有明确需求时按钮只显示文字，不加图标。静态图标、可配置图标及资源加载采用[前端架构](../architecture/frontend.md#页面三层边界)的统一能力，不为视觉复刻重画或另建图标体系。

## 表格视觉

**D-10 必须。** 所有 Ant Design Table 由全局 Table 主题提供四档行背景：普通白色、仅悬停中性灰、选中极淡主题色、选中且悬停稍深主题色。ListPage、RefSelector、可编辑明细和业务弹框表格不得各自覆盖或加斑马纹。

业务状态确需着色时使用业务 rowClassName，并保证选择反馈仍可辨识。不要通过复刻外部斑马纹替换这一选择。验证需覆盖未选/选中与悬停组合，换肤后仍可区分。

文本入口、列声明、分页、滚动和空态分别见页面指南。关键金额和数量遵守[完整值要求](./foundations.md#关键金额与数量)，不因库默认省略而丢失含义。
