# 系统参数

## 模块定位

系统参数保存可以在运行期调整、由业务代码按全局唯一编码读取的非敏感配置。密码、令牌、私钥和加密密钥等敏感凭据不得存入系统参数。

## 参数归属

系统参数只支持两种作用域：

- `feature_id` 为空的是全局参数；
- `feature_id` 有值的是功能参数，所属应用和领域统一由 Feature 推导。

系统参数不保存 `app_id`，也不提供应用级参数。列表左树中的“全部参数”包含领域、应用和功能目录；“全局参数”作为与“全部参数”同级的独立筛选入口，不嵌入业务目录。领域和应用节点分别查询其下全部功能的参数，功能节点只查询直接归属于该功能的参数。禁止通过参数编码前缀推断 Feature 归属。

系统内置参数的编码、名称、描述和功能归属只通过 Flyway 迁移维护，管理界面只允许修改参数值。自定义参数可以选择一个真实存在的 Feature，也可以留空创建为全局参数。

## 缓存与读取

业务代码按参数编码读取值，编码全局唯一。参数保存和删除后统一失效共享参数缓存，保证多实例读取到最新配置。功能归属只用于管理和筛选，不参与运行时参数键解析。

个人消息中心使用全局内置参数 `INBOX_POLL_INTERVAL_SECONDS`，默认 `60` 秒；`0` 关闭定时轮询，启用时为 `10～2147483` 秒的整数。保存校验使用数据库中真实的系统参数编码，不能通过伪造提交编码绕过。生效与关闭后重新获取配置的行为见[站内消息](../message/inbox.md)。
