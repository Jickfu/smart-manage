# 首页快速发起

## 模块边界

首页快速发起是 `sys/base/user` 下的当前用户偏好公共能力，不是独立业务功能，不新增 Feature、菜单或权限码。系统首页或应用首页可以按实际快捷发起需求选择接入；它不是应用首页的必备区块，不接入时不渲染占位。接入后遵循以下范围：

- 系统首页可选择当前用户在当前组织下有权访问的全部应用页面菜单；
- 应用首页只能选择当前应用下有权访问的页面菜单；
- 系统首页与各应用首页分别保存配置，同一用户在不同应用中的配置互不影响；
- 快捷入口只引用稳定菜单记录，不复制组件键、外链或权限关系。

## 安全与一致性

配置归属当前登录用户，接口不接受用户 ID。读取时重新按当前组织、角色和菜单启用状态过滤；保存时必须确认每个菜单仍在当前用户可访问的候选范围内，不能通过提交菜单 ID 绕过授权。

菜单、应用被停用或用户授权变化后，失效入口不会继续返回，但保留的偏好记录不构成授权结果。菜单、应用或用户删除时由外键级联清理对应配置。

## 页面交互

首页快速发起使用固定高度卡片：入口随宽度自动换行，超过卡片高度时在卡片内部滚动；页面其余卡片超出视口时由首页整体纵向滚动。末尾加号打开当前范围的菜单选择弹框，弹框内容区保持稳定高度，树节点展开或折叠只能改变内容区内部滚动状态，不得改变弹框整体高度；保存后刷新该首页的快捷入口。
