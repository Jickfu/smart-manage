# 组织管理

## 模块定位

组织管理维护系统唯一的行政组织树。第一阶段不承载法人、财务、采购、库存、项目或矩阵组织等其他维度。

## 组织结构

- 组织使用单上级树结构，顶级组织的 `parent_id` 为空。
- 组织类型包括集团、公司和部门。集团只能位于顶级；公司可以位于集团或公司下；部门可以位于集团、公司或部门下。
- 编码全局唯一；编码和名称禁止包含 `/`。
- `number_path` 和 `name_path` 分别表示长编码和长名称，只由后端维护。修改编码、名称或上级时，在同一事务内更新全部后代路径。
- 禁止选择自身或自己的后代作为上级，禁止移动到已封存组织下。
- 同级组织按 `sort`、`number`、`id` 升序排列。

## 状态

- 新增组织默认启用且未封存。
- 禁用表示临时不可用；封存表示退出行政体系。
- 封存时强制禁用并记录封存时间；解封时清空封存时间，但保持禁用。
- 已封存组织禁止编辑、移动、启用和作为上级组织。
- 组织存在未封存后代时禁止封存，不执行隐式级联封存。
- 有效组织选项只返回已启用且未封存的组织；历史业务引用不受状态变化影响。
- 组织仍被启用用户作为主职时禁止停用或封存，必须先调整相关用户的主职或禁用用户。
- 组织不提供物理删除能力。

## 页面交互

- 页面采用左树右表。左树直接显示上级为空的顶级组织并默认展开，首次进入默认选中第一个顶级组织。
- 默认显示当前选中组织及其直接下级；勾选“包含下级”后显示当前组织及其全部后代。
- 默认隐藏已封存组织；勾选“显示封存”后，左树和右表均包含已封存组织。
- 新增时默认使用当前树节点作为上级；编码列作为编辑入口。
- 编辑使用通用弹框编辑页，维护编码、名称、上级组织、组织类型、排序和描述。
- 表格上方集中提供新增、编辑、启用、禁用、封存和解封操作，不增加操作列。
