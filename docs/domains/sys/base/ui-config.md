# 界面配置

界面配置是 `sys/base/uiConfig` 下的全局单例配置，沿用既有 Feature、管理页面和详情/保存权限。配置负责登录页品牌图片、系统名称以及登录后主应用的水印表现，不建立动态表单或通用配置引擎。

## 水印边界

- 水印只在登录会话初始化成功后的主应用中渲染，登录页不显示。
- 管理员可以配置启用状态、固定内容、当前用户字段、字体大小以及水平和垂直间距。
- 当前用户字段包括姓名、手机号、邮箱、工号和当前组织所在组织树的绝对顶层组织名称；未设置的字段自动忽略。
- 手机号和邮箱必须在前端合成水印前脱敏，不提供关闭脱敏的配置。
- 活跃界面配置接口只下发字段选择，不组装或返回任何当前用户资料；用户资料来自登录会话。
- 固定内容和有效用户字段均为空时不渲染水印。
- 水平、垂直间距取值范围均为 `20` 到 `500` 像素，默认值为 `100` 像素；前后端和数据库共同约束。
- 字体大小取值范围为 `12` 到 `32` 像素，默认值为 `16` 像素。

水印用于截图追踪和提示，不构成访问控制、数据权限或防截图安全能力。

## 验收基线

- 关闭水印时主应用不产生水印节点，开启后保存配置可即时刷新当前会话的水印。
- 固定内容和每种用户信息分别换行显示，不显示字段标题，空值不产生占位。
- 切换当前组织后，会话重新初始化并使用新组织路径的绝对顶层名称。
- 手机号和邮箱的水印内容不包含联系方式原文。
- 非法间距不能通过接口或数据库约束写入。
